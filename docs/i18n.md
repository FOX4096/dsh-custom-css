# 国际化

[← 返回 README](../README.md) · [文档索引](./index.md)

插件跟着 **DSH 自己的语言**走：DSH 是中文，它就是中文；DSH 切成 English，它立刻变成英文 —— 不需要刷新，
也不需要重装。这一页写清「哪些已经是双语的、哪些还是中文、以及加一条文案的正确姿势」。

## 唯一没翻的：`window.dshCss` 的控制台帮助

`dshCss.help()` 打出来的那张 API 清单仍是中文。理由：它是**开发者**用的（连文档本身都只有中文），
而且每条都在 `docs/authoring-api.md` 里有对应说明 —— 把它翻成英文会让人以为这套 API 面向英文用户，
反而误导。

## 两层词典，为什么分开

| 层 | 机制 | 用在哪 |
| --- | --- | --- |
| 界面文案 | `t('menu.audit')`，两份词典注册进 DSH 的 locale 服务 | 按钮、状态、菜单、错误提示 |
| 内容（CSS 教学表） | `content('字体颜色')`，插件内一张「中文原文 → 英文」表 | 属性字典、值名、分组、模板名与提示 |

内容那一层按**中文原文**索引，是因为那张表本来就是中文优先的（`display` → `显示` → `弹性布局`）。
给 242 条各编一个 key 只会让表更难读，而它需要的是「同一张表的两种语言」。代价写在这里：
**这一层只服务英文** —— 将来有人加日语包，界面会跟着变，属性字典仍显示中文（或他补一张表）。
不假装支持一个没人翻过的语言。

## 加一条文案的正确姿势

```js
// 1. 两份词典都加（少一份会在英文界面里漏出中文，单测会拦）
const STRINGS = {
  zh: { 'menu.audit': '选择器体检' },
  en: { 'menu.audit': 'Check selectors' },
};

// 2. 用 t()，带占位符的值用 {name}
label: t('menu.audit')
hint: t('audit.line', { line: entry.line })
```

三条约定：

- **未登记的键显示中文原文，不显示 key**：翻译是增量的，漏一条不该让界面冒出 `status.saved`。
- **没有 locale 服务的组合（含测试床）行为不变**：`t` 退回只查 zh 表，输出与加国际化之前逐字一致。
- **别在注入浏览器的模板字符串里写反引号**：`tests/visual-probe.mjs` 踩过，注释里的反引号会提前结束模板。

## 语言服务是怎么接上的

DSH 提供 `ctx.locale`（`@deepseek-ai/dsh-client-locale`）：

```js
ctx.effect(() => ctx.locale.register('custom-css', 'zh', STRINGS.zh), '…: zh dictionary');
ctx.effect(() => ctx.locale.register('custom-css', 'en', STRINGS.en), '…: en dictionary');
const t = ctx.locale.bind('custom-css');   // 稳定引用，调用时才读当前语言
ctx.effect(() => ctx.locale.subscribe(() => { /* 让组件重渲染 */ }), '…: locale re-render');
```

本插件把这四步放在 `apply()` 里，并且**服务是可选依赖**：

- 用 `ctx.get('locale')` 先看一眼，没有就 `ctx.inject(['locale'], …)` 等它激活（服务激活可能晚于插件
  挂载 —— `clientModules.release` 上踩过同一个坑）；
- 两条路都没有（精简组合、测试床）就保持中文，什么都不做。

换字不需要重新挂载：`t` 在调用时才读当前语言，而语言切换时我们把两个 store 各推进一步，
挂在 `useSyncExternalStore` 上的组件因此重渲染一次。

## 怎么验

- **单测**：`tests/loader-smoke.cjs` 的 `i18n` 段给了一个假 locale 服务，断言两件事 —— 英文界面里
  中文一条都不漏、两份词典的键集完全一致；再切回中文，同一份组件重渲染即换字。
- **真机**：把开发 profile 的 `locale.preference` 改成 `en` 再重启（`dev/home/profiles/ccdev/cordis.patch.yml`），
  或在设置 → 通用 → 语言里切。插件那一行会立刻变成 `Custom CSS` / `Pick element` / `More actions`，
  插件详情页的壁纸节会变成 `Custom wallpaper` / `Cover · crop the overflow` / `Interface opacity`。
