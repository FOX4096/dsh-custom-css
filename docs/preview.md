## 它是什么

插在**编辑正文**里、**代码区**与**规则面板**之间的一整块（`.dshCc_preview`）。

> 注意位置：别叫它「编辑器下面那块」—— 规则面板也在编辑器下面，这正是以前会混的地方。

预览的是**当前这条规则**：把它的效果显示出来，并且能跟「没有这条规则」并排看。

## 为什么值得做

调一条规则时，现在的循环是「改值 → 看页面 → 找不到刚才改的那个元素」。
预览块把这一圈缩成「改值 → 看预览」，而且可以**并排**看有无这条规则的区别 ——
后者用界面本身做不到（页面只有一份）。

## 顶部与中部

**预览头部**（`.dshCc_previewHead`）一行：

- 左侧 **规则文本**（`.dshCc_previewRule`）：当前规则的原文。
- 右上角 **预览工具组**（`.dshCc_previewTools`）：两个按钮 ——
  **对比按钮**（`.dshCc_previewCompare`，开对比模式）、
  **全屏按钮**（`.dshCc_previewFull`，开全屏视图）。

**状态芯片组**（`.dshCc_stateChips`）：单屏模式下的一排 **状态芯片**（`.dshCc_stateChip`）——
**悬停 / 聚焦 / 占位符 / `::before` / `::after`**。勾选哪个，预览就把那个状态演出来
（`:hover` 与 `:focus` 在真实页面上没法同时看到，这正是需要预览的原因）。

选中 / 未选中用 `--dsw-alias-interactive-bg-active` / `--dsw-alias-bg-module-platform` 区分。

**预览视口**（`.dshCc_previewStage`）：装预览的框。**是一个 iframe** —— 理由见下。

## 两种模式

| 模式 | 预览视口的内容 | 视口标签 |
| --- | --- | --- |
| **单屏预览**（默认） | 一个视口：整张表**含这条规则** | 无 |
| **对比预览**（对比模式） | 两个视口并排：**原始视口** \| **修改后视口** | 各带左上角的 `原始` / `修改后` 与角上的**尺寸读数**（如 `320×180`） |

「整表」很关键：**要看到这条规则在真实上下文里的效果**，而不是把那些声明孤立地应用到一个空元素上 ——
很多规则的效果取决于它前面那些规则的级联。

- **原始视口** = 整张表**减掉这条规则**（用 `--dsw-alias-code-diff-deleted` 做点缀色）
- **修改后视口** = 整表**含这条规则**（用 `--dsw-alias-code-diff-added`）

窄行（约 440px）下的对比模式：**上下堆叠**，不提示「先全屏」。

## 为什么用 iframe，以及为什么克隆

这是整块设计里唯一有真正取舍的地方。

要在同一屏上展示「有这条规则」与「没有这条规则」的**同一个元素**，只有两条路：

1. 在真页面上切换样式表 → 整页闪一下，而且会打断你正在看的东西
2. 把元素**克隆**进一个隔离的容器，在容器里注入两种样式表

选 2，容器用 **iframe**：它的样式作用域天然隔离，不需要给每条规则加前缀，
也不会与 `docs/` 里说的「注入顺序不定」那类问题纠缠。

克隆意味着：**预览里的元素与页面上的元素是两个节点** ——
所以预览里的交互（真的 `:hover`）需要我们自己驱动（这就是**状态芯片**的用途），
而不是等鼠标真的移上去。

## 命中 0 个时怎么办

用**合成样本**：拿真令牌拼一个替代元素，并**明确标注**它不是页面上的东西。

「明确标注」是硬要求 —— 否则用户会以为页面上真有那么个元素，然后去页面上找它。

## 边界情况

| 情况 | 怎么办 |
| --- | --- |
| 当前规则命中 **0 个**元素 | 用**合成样本**并标注（见上） |
| 当前规则写在**伪元素**上（`a::before`） | 预览宿主元素本身，并用状态芯片把 `::before` / `::after` 打开 |
| 当前规则在 `@media` / `@supports` 里 | 面板本来就编辑不到它（见 [已知限制](./known-issues.md)），预览块同理：不显示 |
| 样式表很大 | 只往 iframe 里注入**当前这条规则 + 它依赖的令牌定义**，不是整表 —— 注太多会让预览重到失去意义 |
| 属性面板里的值正在被编辑 | 预览跟随**已写盘的值**，不跟半输入的值（与 [规则面板](./rule-panel.md) 的校验口径一致） |

## 全屏视图

**全屏视图**（`.dshCc_full`）盖在整行之上，由**全屏按钮**打开：

```
全屏视图
├── 全屏遮罩（--dsw-alias-bg-overlay）
└── 全屏卡片（--dsw-alias-settings-card-fill + -stroke，阴影 --dsw-elevation-prominent）
    ├── 全屏顶栏 → 全屏选择器框 + 全屏退出钮
    ├── 全屏预览区 → 原始视口 | 修改后视口
    └── 全屏规则面板（就是编辑器里那个规则面板）
```

全屏时**顶部只显示该规则的文本框**，下方左原文预览、右自定义 CSS 之后的预览，再下面接规则面板 ——
也就是把「改值」与「看效果」放在同一屏里，不用在长页面之间来回滚。
