# 示例

两份可以直接导入的样式表，用途不同：

| 文件 | 适合谁 | 它演示什么 |
| --- | --- | --- |
| [`showcase.css`](./showcase.css) | **想学怎么写**自定义 CSS | 最小而安全的一组改动：只用设计变量、不选构建哈希类名、不写 `!important`。60 行，读得完 |
| [`acrylic.css`](./acrylic.css) | **想直接要个好看的皮肤** | 完整的亚克力（Acrylic）皮肤：渐变壁纸 + 半透明玻璃面板 + 背景模糊。约 400 行，覆盖全界面 |

两份都是**导入即用**，不改动仓库里的任何东西。

## 用它

1. 打开 **设置 → 通用 → 自定义 CSS**；
2. 点「**导入**」选中要用的那份（会作为新的样式表加入 `~/.dsh/custom-css/`，原文件不受影响）；
3. 想还原就在文件下拉里选回原来的样式表 —— 或者用「重置」清空当前文件。

## `acrylic.css` 怎么调

**只改文件开头 §0 的变量**：

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `--dsh-acrylic-tone-a/b/c` | 壁纸的三个色相（用 DSH 的静态色令牌） | 蓝 / 绿 / 琥珀 |
| `--dsh-acrylic-shell-tint` | 壳体（铺满整个视口那层玻璃）的浓度 | `18%` |
| `--dsh-acrylic-side-tint` | 侧栏 / 右栏那类**整列**容器的浓度 | `34%` |
| `--dsh-acrylic-panel-tint` | 面板（输入卡片、菜单、对话框）的浓度 | `62%` |
| `--dsh-acrylic-chip-tint` | 小控件（按钮、模式选择、入口卡片）的浓度 | `45%` |
| `--dsh-acrylic-blur` | 模糊半径，照抄 DSH 自己菜单的 `blur(40px)` | `40px` |
| `--dsh-acrylic-saturate` | 模糊时顺带提的饱和度 | `150%` |
| `--dsh-acrylic-drift` | 壁纸漂移周期，越大越省电 | `48s` |

**四档浓度是按面积分的，这是整套皮肤最要紧的一条规律**：白玻璃叠在浅色壁纸上，
浓度高了**渲染出来就是白的**，看起来像"根本没做玻璃"。所以面积越大浓度必须越低 ——
壳体铺满视口所以最淡（18%），面板面积小所以最实（62%，要保住文字可读性）。
如果你觉得玻璃感不够，**先调淡**而不是调浓。

**这里没有"圆角"参数**：DSH 的对话框、菜单、卡片各有自己的圆角规格，
皮肤只换材质（底色 / 模糊 / 描边 / 阴影），不动它的几何。

### 换掉壁纸

§1 那四团光斑就是壁纸。想换成纯色，把 `body::before` 整块删掉、在 `body` 上写
`background: <你的颜色>` 即可 —— 玻璃会自动去模糊它。

### 关掉壁纸漂移

删掉 §1 末尾那段 `@media (prefers-reduced-motion: no-preference)` 里的 `animation`。
如果系统本身设了「减少动态效果」，它已经不会动。

## 三条经验（写自己的样式表时）

| 经验 | 原因 |
| --- | --- |
| 需要压过内置样式时用 `!important` | 自定义样式与内置样式表特异性相同时，谁后插入谁赢，而插入时机不受你控制（见 [`docs/known-issues.md`](../docs/known-issues.md)） |
| 别长期依赖构建哈希类名（`hHd-Xa_footArea`） | 名字随 DSH 版本变；要用就从 DOM 里现抓，且抓类名的正则**必须包含 `-`** |
| `:has()` 只写一层 | 嵌套 `:has()` 会让 Chrome 抛 `is not a valid selector`，**整条规则被静默丢弃** |

## 写玻璃材质时的两条额外经验（`acrylic.css` 踩出来的）

| 经验 | 原因 |
| --- | --- |
| **变量引用 DSH 令牌时，必须定义在 `body` 上，不能放 `:root`** | DSH 把全部 `--dsw-*` 定义在 **`body`** 上。在 `:root` 里写 `--x: var(--dsw-…)` 会解析成空值，接着**整条依赖它的声明被静默丢弃**（壁纸就是这么消失的，浏览器不报错） |
| **玻璃面加在"拥有底色的那个元素"上** | 给祖先加会形成 backdrop root，嵌套菜单与 fixed 浮层会跟着受影响（DSH 自己的注释也强调这点）。而且要留意：常见容器往往是**实心白**，得先把它的底让开，玻璃才透得上来 |
| **壁纸这类固定尺寸的元素，`inset` 别乱扩** | 写 `inset: -20%` 想给动画留余量，会让元素比视口大 40%，于是 `radial-gradient(… at 82% …)` 的右边缘落到**视口之外**，右半边只剩 `transparent` —— 看起来像"壁纸只铺了左半边" |

更多（描述符块、自定义属性动画、host 半需重启等）见 [`docs/known-issues.md`](../docs/known-issues.md)。
